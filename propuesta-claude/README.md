# Propuesta Claude · «Cockpit Tierra» (concurso 027)

Prototipo estático, **no se publica** y no forma parte de la web (está fuera de `apps/web`). Datos de ejemplo.

- `index.html`: portada (móvil y escritorio) con la maqueta 4D interactiva (`maqueta.js`, CSS 3D sin librerías).
- `ficha.html`: ficha de una casa.
- `estilo.css`: paleta, tipografía y componentes. `fuentes.css` + `fuentes/`: Manrope y Michroma (SIL OFL 1.1), alojadas aquí.
- `capturas/`: vistas a 390 y 1440 px.

Para verlo: abrir `index.html` en el navegador (no necesita servidor).
